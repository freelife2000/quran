تنسيق ملفات الترجمات

نقترح استخدام أحد الشكلين التاليين لكل لغة:

1) JSON مُتداخل (مفضل):
{
  "1": {"1": "...", "2": "..."},
  "2": {"1": "...", "255": "..."}
}

- مفاتيح السور والآيات كـسلاسل (أو أرقام). هذا يجعل الدمج بسيطًا.
- ملف لكل لغة، يسمّى مثلًا: `en.json`, `fr.json`, `ar.json`.

2) CSV (احتياطي):
- رأس بالحد الأدنى: `sura_no,aya_no,translation`

مثال `en_example.json` موجود هنا كمثال لملف لغة إنجليزية بسيط.
