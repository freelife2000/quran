تنسيق ملفات أسباب النزول (أسباب النزول)

نقترح تنسيق JSON على النحو التالي:
{
  "sura_no": {
    "aya_no": [
      {
        "text": "نص السبب...",
        "source": "المصدر (مثال: سبب من الطبري وغيره)",
        "note": "حقل اختياري للملاحظات"
      }
    ]
  }
}

أو CSV مع رؤوس: `sura_no,aya_no,asbab_text,source`.

ملف قالب `template_asbab.json` مثال لاستخدامه.
