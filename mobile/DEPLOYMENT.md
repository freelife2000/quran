# Quran App Mobile - النشر على متجر بلاي

هذا الدليل يشرح خطوات النشر الكاملة لتطبيق القرآن الكريم على Google Play Store.

## المتطلبات الأساسية

### 1. حساب Google Play
- إنشاء حساب Google
- دفع رسم التسجيل ($25 مرة واحدة)
- رابط: https://play.google.com/console

### 2. والأدوات المطلوبة
```bash
npm install -g eas-cli
npm install -g expo-cli
```

### 3. حساب Expo
- التسجيل على https://expo.dev
- تسجيل الدخول عبر CLI:
```bash
eas login
```

## خطوات النشر الكاملة

### المرحلة 1: التجهيز والإعدادات

#### 1.1 تحديث معلومات التطبيق في `app.json`
```json
{
  "expo": {
    "name": "Quran App",
    "slug": "quran-app",
    "version": "1.0.0",
    "android": {
      "versionCode": 1,
      "package": "com.freelife2000.quranapp"
    }
  }
}
```

#### 1.2 إضافة أيقونات التطبيق
- أيقونة بحجم 1080x1080 بصيغة PNG
ضعها في `assets/icon.png`

#### 1.3 إعداد الصور
- 4-8 لقطات شاشة بدقة عالية (1080x1920)
- صورة غلاف (1024x500)

### المرحلة 2: البناء (Compilation)

#### 2.1 بناء APK/AAB عبر Expo
```bash
# البناء الأول (قد يسأل عن معلومات التوقيع)
eas build --platform android
```

#### 2.2 اختيار نوع البناء
عند السؤال، اختر:
- **AAB (Android App Bundle)** - للمتجر ✅ الموصى به
- **APK** - للتوزيع المباشر

#### 2.3 انتظار البناء
- المدة: 5-15 دقيقة
- ستحصل على رابط تحميل الملف الناهي

### المرحلة 3: إعداد Google Play Console

#### 3.1 إنشاء قائمة التطبيق
```
Google Play Console → بدء مشروع جديد → Quran App
```

#### 3.2 إدخال معلومات التطبيق
- **الاسم**: Quran App - تطبيق القرآن الكريم
- **الفئة**: كتب ومراجع / تعليم / دين
- **المصنف**: 12+ أو 16+
- **الوصف**:
```
تطبيق القرآن الكريم الشامل - Quran Mobile App

اقرأ القرآن الكريم مع أكثر من 60 ترجمة متاحة بجميع اللغات العالمية.
يوفر التطبيق:

📖 القرآن الكريم الكامل مع التفاسير
🌍 ترجمات متعددة اللغات
🕌 أوقات الصلاة حسب موقعك
🤲 أذكار يومية وإسلامية
🔖 حفظ الآيات المفضلة
🔍 بحث سريع في القرآن

الميزات:
✨ واجهة سهلة الاستخدام بالعربية
✨ دعم كامل للعربية والقراءة من اليمين لليسار
✨ وصول سريع بدون إنترنت (بعد التحميل)
✨ تصميم جميل وحديث
✨ محسّن للأداء على جميع الأجهزة

تطبيق موثوق وآمن. لا إعلانات مزعجة.
مجاني تماماً والكود مفتوح المصدر.
```

#### 3.3 إضافة الصور
- **أيقونة التطبيق**: 512x512 PNG
- **غلاف الميزات**: 1024x500 PNG
- **لقطات الشاشة**: 4-8 لقطات بدقة عالية

#### 3.4 سياسة الخصوصية
أضف رابط سياسة الخصوصية:
```
https://github.com/freelife2000/quran/blob/main/PRIVACY.md
```

### المرحلة 4: رفع البناء

#### 4.1 ذهاب إلى إصدار الإنتاج
```
Google Play Console → 
الإصدارات → الإنتاج → 
إنشاء إصدار جديد
```

#### 4.2 تحميل ملف AAB
- اختر الملف من `eas build`
- تأكد من رقم الإصدار (Version Code)

#### 4.3 إضافة ملاحظات الإصدار
```
الإصدار الأول: تطبيق القرآن الكريم مع الترجمات والتفاسير
```

#### 4.4 التدرج التدريجي (اختياري)
- ابدأ بـ 10% من المستخدمين في اليوم الأول
- زيادة تدريجية

### المرحلة 5: المراجعة والموافقة

#### المدة
- 2-4 ساعات عادة
- قد تستغرق 24 ساعة في الحالات النادرة

#### المتطلبات الشائعة
✅ يجب أن يعمل التطبيق بدون أخطاء
✅ واجهة واضحة وقابلة للاستخدام
✅ عدم وجود محتوى ضار
✅ سياسة خصوصية واضحة
✅ وصف دقيق للتطبيق

#### في حالة الرفض
- اقرأ ملاحظات الفريق بعناية
- حل المشاكل المذكورة
- أعد الرفع

### المرحلة 6: التحديثات المستقبلية

#### تحديث الإصدارات
```bash
# زيادة رقم الإصدار في app.json
{
  "version": "1.1.0",
  "android": {
    "versionCode": 2  // يجب أن يزداد دائماً
  }
}

# بناء جديد
eas build --platform android

# رفع إلى متجر بلاي
```

## نصائح مهمة

### الأمان
- لا تخزن مفاتيح API في الكود
- استخدم `.env` للمتغيرات الحساسة
- فعّل HTTPS للاتصالات

### الأداء
- حسّن حجم التطبيق
- استخدم Lazy Loading للبيانات الكبيرة
- اختبر على أجهزة ضعيفة

### التسويق
- اطلب التقييمات من المستخدمين
- اجع الاستعراضات بسرعة
- حدّث الميزات بانتظام

### الحماية
- من الضروري الامتثال لسياسة الخصوصية
- احصل على موافقة المستخدمين للبيانات

## استكشاف الأخطاء الشائعة

### خطأ: "Signature mismatch"
```bash
# أعد إنشاء التوقيع
eas credentials
```

### خطأ: "Version code too low"
- زد `versionCode` في `app.json`
- كل تحديث يحتاج رقم أعلى

### التطبيق مرفوع لكن لا يظهر
- انتظر حتى 24 ساعة
- البحث عن اسم المتجر الكامل

### الإعلانات المرفوعة
- لا تصرح بأن التطبيق خالي من الإعلانات إن لم يكن كذلك
- كن صادقاً في الوصف
